# 탁구 대회 대진표

학급 탁구 대회용 팀 구성 · 대진표 웹 앱입니다. 설치나 서버 없이 브라우저에서 바로 엽니다.

## 실행 방법

`index.html` 파일을 브라우저로 여세요.

- 탐색기에서 `index.html`을 더블클릭하거나
- 파일을 Chrome / Edge 창으로 끌어다 놓으면 됩니다.

## 사용 순서

1. **멤버** — 학급 명단(번호 순)을 확인하고, 학급 밖 사람은 이름을 입력해 추가합니다. 외부 인원은 새로고침 후에도 유지됩니다.
2. **에이스** — 팀마다 에이스 한 명을 고릅니다. 같은 사람은 두 팀의 에이스가 될 수 없습니다. 에이스 수 = 팀 수입니다.
3. **팀** — 자동 구성 후 클릭/드래그로 인원을 옮깁니다. 한 팀은 1~3명입니다. 정원에 안 들어가는 사람은 미배정으로 남습니다.
4. **대진표** — 싱글 엘리미네이션 대진표를 만들고, 필요하면 다시 섞거나 승자를 눌러 다음 라운드로 올립니다. 인쇄도 가능합니다.
5. **점수판** — 11점제(2점 차) 점수판입니다. 3판 2선승 또는 5판 3선승을 고르고, 큰 +1 / −1 버튼이나 키보드로 점수를 올립니다. 대진표 경기의 「점수판」을 누르면 그 팀이 열리고, 경기가 끝나면 「대진표에 승자 반영」으로 승자를 올릴 수 있습니다. 점수와 서브는 이 브라우저에 저장됩니다.

키보드: `A` / `←` 왼쪽 +1, `D` / `→` 오른쪽 +1, `Z` 왼쪽 −1, `C` 오른쪽 −1, `Backspace` 한 점 취소.

## 학급 명단

번호 순 고정 명단입니다. 학급 멤버는 삭제할 수 없습니다.
